Gerenciar agenda

Área da equipe Kairavana. Aqui você fecha dias, marca horários reservados e ajusta a semana de atendimento. As mudanças aparecem no site em cerca de 1 a 2 minutos.

Como criar a chave de acesso
  1. Entre no GitHub com a conta dona do site e abra github.com/settings/personal-access-tokens/new.
  2. Em Token name, escreva algo como agenda kairavana. Escolha a validade que preferir (por exemplo, 1 ano).
  3. Em Repository access, marque Only select repositories e escolha kairavana.
  4. Em Permissions → Repository permissions → Contents, escolha Read and write.
  5. Clique em Generate token, copie a chave e cole aqui. Guarde-a em um lugar seguro: o GitHub só mostra uma vez.

A chave dá acesso apenas a este site. Não compartilhe com ninguém. Se perder o aparelho, apague a chave no GitHub e crie outra.

Dias e reservas

Escolha um dia. Toque num horário para marcá-lo como reservado quando alguém agendar, ou feche o dia inteiro.

Semana padrão

Horários que se repetem toda semana. Deixe um dia sem horários para não atender nele.

Contato e regras gerais da agenda.
